# MarkdownPad

Markdown ファイルを、メモ帳の手軽さで開いて、きれいに読み書きできる
Windows アプリです。Linux 版もあります。

Obsidian は表示が美しい一方で、ノートを Vault で管理する前提です。
VS Code は、少し読んで直すだけには大がかりです。メモ帳は軽いものの、
Markdown を整形して表示できません。MarkdownPad はその間を埋めます。
ファイルをダブルクリックすればすぐに開き、整形された状態のまま編集
できます。

## 特長

- **ファイルを開くだけ**: Vault やプロジェクトの管理はありません。
  1 つの `.md` ファイルをそのまま開いて保存します。
- **ライブプレビュー**: 書いている行だけ Markdown の記法を表示し、
  ほかの部分は見出し・表・コードブロックなどの整形された表示のまま
  編集できます。
- **リーディングモード**: `Ctrl+E` で、うっかり書き換えずに読むための
  表示に切り替わります。
- **ファイルの形式を保つ**: 文字コード（UTF-8、UTF-16、Shift_JIS）と
  改行コードは、開いたときの形式のまま保存します。
- **勝手に保存しない**: ファイルが変わるのは、保存したときだけです。
  アプリが異常終了したときは、未保存の内容を次の起動時に復元できます。
- **ライト / ダークテーマ**: 初めは Windows の設定に合わせ、右上の
  ボタンで切り替えられます。

## インストール

インストーラーはありません。Windows は zip を展開して、中の exe を起動
するだけです。Linux は [下記](#linux) を参照してください。

1. [Releases](https://github.com/DJMIMA/MarkdownPad/releases/latest)
   から `MarkdownPad-<バージョン>-windows-x64.zip` をダウンロードする。
2. 好きな場所に展開する（例: `C:\Tools\MarkdownPad`）。
3. `MarkdownPad.exe` を起動する。

zip には `MarkdownPad.exe` のほか、ライセンス文（`LICENSE.txt`、
`THIRD-PARTY-NOTICES.txt`）が入っています。

動作環境は、Windows 10 / 11（64 ビット）と Microsoft Edge WebView2
Runtime です。WebView2 は Windows 11 には標準で入っています。入って
いない場合は [Microsoft のページ](https://developer.microsoft.com/microsoft-edge/webview2/)
から入手できます。

exe にはコード署名をしていないため、初回の起動時に「Windows によって
PC が保護されました」と表示されることがあります。その場合は「詳細情報」
→「実行」で起動できます。

### Linux

1. [Releases](https://github.com/DJMIMA/MarkdownPad/releases/latest)
   から `MarkdownPad-<バージョン>-linux-x64.tar.gz` をダウンロードする。
2. 展開して、実行ファイル `markdownpad` をパスの通った場所に置く。

   ```bash
   tar -xzf MarkdownPad-<バージョン>-linux-x64.tar.gz
   install -Dm755 MarkdownPad/markdownpad ~/.local/bin/markdownpad
   ```

3. `markdownpad` を起動する。開くファイルを引数で渡すこともできます。

tar.gz には `markdownpad` のほか、ライセンス文（`LICENSE.txt`、
`THIRD-PARTY-NOTICES.txt`）が入っています。

動作環境は 64 ビット（x86_64）の Linux で、GTK 3 と WebKitGTK 4.1 が
必要です。Ubuntu 22.04 以降、Debian 12 以降などで動きます。入っていない
場合は、Ubuntu / Debian なら次のコマンドで入ります。

```bash
sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0
```

### .md ファイルをダブルクリックで開く

「ファイル」→「設定」（`Ctrl+,`）の「ファイルの関連付け」で設定します。

1. 「関連付けを登録」を押す。`.md` と `.markdown` の「プログラムから
   開く」に MarkdownPad が加わり、Windows の「既定のアプリ」設定が開く。
2. 開いた設定画面で、`.md` と `.markdown` の既定に MarkdownPad を
   選ぶ。Windows では、既定のアプリはアプリ自身では変更できず、利用者が
   選ぶ必要があります。

設定画面には、拡張子ごとに今どのアプリで開くかが表示されます。登録は
現在のユーザーだけに対して行い、管理者権限は要りません。exe を別の
フォルダへ移したときは、「この場所で登録し直す」を押します。
「登録を解除」すると、MarkdownPad を既定にしていた拡張子は、Windows が
ほかのアプリで開くか、どのアプリで開くかを尋ねるようになります。

Linux 版では、「関連付けを登録」を押すとアプリ一覧に MarkdownPad が
加わり、そのまま `.md` と `.markdown` の既定のアプリにもなります。登録は
起動中の `markdownpad` の場所を指すので、置き場所を決めてから登録して
ください。「登録を解除」すると、以前の既定のアプリに戻ります。

### 更新とアンインストール

- 更新: 新しいバージョンの zip を展開し、`MarkdownPad.exe` を置き換え
  ます。テーマの選択は exe とは別の場所に保存されているので、そのまま
  引き継がれます。
- アンインストール: 関連付けを登録していた場合は、先に「設定」の
  「登録を解除」を押します。そのあと、展開したフォルダを削除します。アプリのデータも
  消す場合は、`%APPDATA%\com.markdownpad.app` と
  `%LOCALAPPDATA%\com.markdownpad.app` も削除します。
- Linux: 更新は `markdownpad` を新しいものに置き換えます。アンインストール
  は、関連付けを登録していた場合は先に「登録を解除」を押してから
  `markdownpad` を削除します。アプリのデータは
  `~/.local/share/com.markdownpad.app` にあります。

## 使い方

### ライブプレビュー

文書は常に整形されて表示されます。カーソルのある行だけ、`#` や `**`、
リンクの `[...](...)` などの記法が現れるので、記法を直接書き換えられ
ます。表、コードブロック、罫線は、クリックするとブロック全体が Markdown
のソースに戻ります。

明示的なリンク `[文字](URL)` はクリックすると既定のブラウザで開きます。
文中にそのまま書いた URL はリンクにしません。

### リストの編集

| キー | 動作 |
| --- | --- |
| `Enter` | 次の項目を作る。空の項目で押すとリストを抜ける |
| `Shift+Enter` | 同じ項目の中で改行する |
| `Tab` / `Shift+Tab` | 項目を 1 段深くする / 浅くする |

リストの外では `Tab` はタブ文字を入力します。キーボードだけでエディタ
の外へ移るときは、`Esc` を押してから `Tab` を押します。

### リーディングモード

「表示」→「リーディングモード」（`Ctrl+E`）で、編集できない閲覧用の
表示になります。表やコードブロックをクリックしてもソースに戻らず、
文字の入力や貼り付けも受け付けません。選択とコピー、検索、リンクを
開く操作は使えます。矢印キーや `Space`、`PageUp` / `PageDown` は
スクロールになります。

モードはタブごとに切り替わります。もう一度 `Ctrl+E` を押すと編集に
戻ります。

### 保存と復元

- 保存は `Ctrl+S` で行います。自動保存はしません。
- 開いた後にほかのアプリでファイルが変更されていた場合は、上書きする
  前に確認します。
- 元の文字コードで表せない文字を含むときは、UTF-8 で保存するか確認
  します。現在の文字コードと改行コードはステータスバーに表示されます。
- アプリが異常終了したときは、次の起動時に「前回アプリが異常終了して
  います。復元しますか？」と確認します。復元すると、未保存の内容を
  含めて、開いていたタブが戻ります。普段どおりに閉じたときは、次回は
  空のタブで起動します。
- アプリの起動中にほかの `.md` ファイルを開くと、新しいウインドウでは
  なく、最後に使っていたウインドウの新しいタブで開きます。

### キーボードショートカット

| 操作 | キー |
| --- | --- |
| 新しいタブ / 新しいウインドウ | `Ctrl+N` / `Ctrl+Shift+N` |
| 開く | `Ctrl+O` |
| 保存 / 名前を付けて保存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 印刷 | `Ctrl+P` |
| 設定 | `Ctrl+,` |
| タブを閉じる / ウインドウを閉じる | `Ctrl+W` / `Ctrl+Shift+W` |
| 検索 / 置換 | `Ctrl+F` / `Ctrl+H` |
| 次を検索 / 前を検索 | `F3` / `Shift+F3` |
| 拡大 / 縮小 / 既定値に戻す | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| リーディングモード | `Ctrl+E` |

「右端で折り返す」と「ステータスバー」の表示は「表示」メニューで
切り替えます。

## 対応する Markdown

CommonMark と GitHub Flavored Markdown に対応しています。

- 見出し、段落、強調、太字、取り消し線
- 引用
- 箇条書き、番号付きリスト、タスクリスト
- リンク、画像
- インラインコード、コードブロック
- 表
- 水平罫線

画像は、文書のあるフォルダからの相対パス（`../` を含む）か URL で
指定します。まだ保存していない文書では、相対パスの画像は表示されま
せん。

HTML タグは、エディタでは文字のまま表示し、印刷では安全なものだけを
反映します。wikilink（`[[...]]`）や callout など、Obsidian 独自の記法
には対応していません。

## プライバシーと安全性

- 利用状況の送信や自動更新の確認はしません。ネットワークを使うのは、
  文書に書かれた URL の画像を表示するときと、リンクをブラウザで開く
  ときだけです。
- 文書は信頼できない入力として扱います。文書の中のスクリプトは実行
  しません。アプリが開けるのは、利用者が開いたファイルと、その文書が
  参照している画像だけです。
